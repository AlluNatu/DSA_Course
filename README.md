# BM40A1500 Data Structures and Algorithms course

This is repository for my course I completed in LUT University while doing my Bachelors Degree in Computer Science.

This contains my BM40A1500 Data Structures and Algorithms course work (LUT University).


## Learning Objectives
After completing the course, I learned/am able to:

    - The student understands algorithm analysis methods and is able to assess the complexity of an algorithm.
    - The student can select an appropriate algorithm design principle and data structure for a given problem. 
    - The student is capable of writing an algorithm that utilizes advanced data structures and programming it in Python.

## Course Content

    Algorithmic problem solving.
    Data structures.
    Algorithm design principles.
    Algorithm analysis methods.
    Algorithm efficiency.
    NP-completeness.
    Approximation and randomized algorithms.
    Common problem types and appropriate data structures: sorting, searching, and graph problems, as well as stacks, queues, lists, heaps, hash tables, and tree structures.
    Practical implementation of data structures in Python.
